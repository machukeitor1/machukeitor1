### 🚀 Proyectos destacados

#### 🏠 Revestimientos Chillán — Catálogo web y sistema de cotizaciones · *en producción*
`Next.js 14` `TypeScript` `Prisma` `PostgreSQL` `Tailwind` `Vercel`

Sitio de una tienda de pisos y revestimientos: catálogo público con cotización por WhatsApp, panel admin con CRUD e importación desde Excel, y portal de vendedores que genera cotizaciones en PDF y Word. Login con JWT por roles.

🔗 [revestimientoschillan.cl](https://www.revestimientoschillan.cl) · 📂 [Demo del código fuente](https://github.com/machukeitor1/demopisos-catalog)

#### 🏥 OB Care — Sistema de Gestión Obstétrica · *Proyecto Integrado INACAP, equipo de 4*
`Django 5` `MySQL` `Django REST Framework` `pytest`

Sistema clínico con 5 roles (médico, matrona, TENS, administrador, paciente), fichas de parto y recién nacido. Mi aporte: módulo Médico, integración con el sistema heredado (`legacyApp`), mejoras al módulo Matrona, alertas de la Ley 19.628 y testing y seguridad con pytest, Locust y Bandit.

📂 [Repositorio](https://github.com/rjoserivera/OB_Care_Sistema_de_Gestion_Obstetrica)

#### 🔍 Búsqueda por Rol CL — Android + Web
`Kotlin` `Coroutines` `Node.js` `Express`

Consulta el ROL de avalúo de una propiedad en Chile por dirección (SII) y descarga el certificado de deuda de contribuciones (TGR) en PDF. App Android nativa y versión web con API propia.

📂 [App Android](https://github.com/machukeitor1/Busqueda-por-Rol-CL) · 📂 [Versión web](https://github.com/machukeitor1/busquedapropietarioweb)
